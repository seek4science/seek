# Dead / Obsolete Routes Report: `config/routes.rb`

Scan date: 2026-11-26, branch `dead-code-routes`.

## Method

1. **Route → action resolution (runtime).** I loaded every route from `Rails.application.routes` in a
   `rails runner` (1,793 controller routes in total, engines included). For each route I checked:
   - whether the controller class exists
   - whether the action is in `Controller.action_methods`
   - if the action is missing, whether a template at `app/views/<controller>/<action>.*` would render
     it implicitly

   Results: **1,590 ok, 18 template-only (implicit render, fine), 169 missing action, 15 missing
   controller, 1 private method**.
2. **Usage scan of resolvable custom routes.** For each of the 262 non-CRUD custom actions, I
   searched `app/`, `lib/`, `config/` and `public/javascripts` for:
   - the action name, ignoring `def`, `before_action ... only:` lists and `permissions/translator.rb`
   - the named route helpers (`*_path` and `*_url`)
   - a literal URL segment `/<action>`

   Routes with no hits were then checked by hand.
3. **Reverse check.** I listed public methods that each controller defines itself but no route
   reaches. These are dead actions, or helpers that should be `private`.

Caveat: SEEK builds many URLs dynamically, through `polymorphic_path(item, action: ...)`,
`url_for(action:)` and hand-built JS strings. Every item marked "remove" below was confirmed by hand.
Anything I couldn't confirm is marked as needing review.

## Summary: suggested clean-up, in priority order

1. Delete routes to missing controllers: `attachments`, `specimens` (5 nestings), `svg`, `data_fuse`.
2. Delete the custom routes with no action (section 2) and fix the concern misuse (2a), especially
   `collections :has_doi`, snapshot `retract_doi*`/`index`, and the `file_templates`/`placeholders`
   collection blocks.
3. Add `only:` to the over-broad `resources` (section 3) and nested resources (section 4). The
   `observation_units` nesting alone removes 77 routes.
4. Review section 5. Likely removals: `isa_colours`, `request_all`, `attribute_form`,
   `disassociate_authors`, `send_policy_data`, `reset_fatals`, and the duplicate tag/index aliases.
5. Remove the dead controller actions in section 7 (`homes#faq/recent_changes/seek_intro_demo`,
   `placeholders#resolve/update_template`, `data_files#update_template`) with their templates. Make
   the remaining public helpers `private`.

In total, about **185 routes resolve to nothing**, plus about 100 more that resolve to real actions
but are reachable only through unintended nesting.
